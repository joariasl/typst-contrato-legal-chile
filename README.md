# typst-contrato-legal-chile

Plantilla en Typst para redactar contratos legales en Chile, con un formato base formal y contenido de ejemplo en español.

## Contenido del template

El archivo `/tmp/workspace/joariasl/typst-contrato-legal-chile/main.typ` ahora incluye:

- comparecencia inicial de las partes;
- individualización del cliente y del prestador;
- cláusulas modelo para objeto, alcance, honorarios, vigencia, confidencialidad y término anticipado;
- bloque de firmas listo para completar;
- placeholders entre corchetes para adaptar el documento a cada contrato.

## Uso

1. Reemplaza los textos entre corchetes por los datos reales del contrato.
2. Ajusta, agrega o elimina cláusulas según el tipo de instrumento que necesites.
3. Compila el archivo con Typst.

## Compilación

Instala Typst desde su repositorio oficial: <https://github.com/typst/typst#installation>

```bash
typst compile main.typ
```
